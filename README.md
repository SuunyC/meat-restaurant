# Ember & Grill

A responsive meat restaurant website built with HTML and CSS.

## Files

- `index.html` — website structure
- `style.css` — responsive styling
- `steak.jpg images` — supplied restaurant image

## Image Usage

The supplied steak image is used:
- As the hero background
- In the About section
- In all 6 menu/price cards

## Run

Open `index.html` in a browser.

## GitHub Pages

Upload all three files and the image to your GitHub repository, then enable GitHub Pages from the repository settings.
